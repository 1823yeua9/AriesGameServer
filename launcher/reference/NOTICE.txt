Port changes: GLSL to HLSL, Windows D3D11 resources instead of KWin/OpenGL,
snake_case identifiers, square opaque output, source-equivalent color math,
fixed reproducible noise seed instead of a time seed. Only the default clamp
refraction mode is implemented. No source from the game/loader is used here.

Default reference settings from blur.kcfg and settings.cpp:
blur strength 15 => 4 levels, offset 8; grain strength 5;
brightness/saturation/contrast 1; corner radii 0; opacity 100%; refraction off.

Launcher presentation overrides: noise_strength=0, requested after the default
grain looked powdery; strength 14 (4 levels, offset 3 + 5/6 * 5 = 7.166667),
requested for slightly less blur. The underlying blur filter is unchanged.

Matching these settings is not a claim of bit-identical compositor output on
every desktop. GLSL/D3D filtering/rounding, noise seeds, DPI, HDR, source pixels,
and application tint layers can differ. Tests compare the pinned shader math
with RGBA8 per-pass quantization; actual KWin execution is not available here.
